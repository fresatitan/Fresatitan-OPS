Resumen ejecutivo

FRESATITAN OPS es una plataforma digital completa que sustituye el control manual de procesos del laboratorio por un sistema profesional en tiempo real. Permite a los trabajadores registrar su actividad desde tablets en planta mientras la dirección monitoriza todo el flujo desde el ordenador, sin necesidad de recopilar datos manualmente.

El proyecto se entrega como dos aplicaciones conectadas: una web para administración y una aplicación móvil Android (APK) para los operarios en planta. Ambas comparten la misma base de datos y se sincronizan al instante.

1Análisis inicial y diseño

Estudio previo del negocio y definición de la arquitectura de la solución.
  • Análisis de necesidades: estudio de los procesos del laboratorio (12 máquinas, 8 trabajadores, procesos CAD-CAM dental)
  • Diseño de dos experiencias diferenciadas: una para operarios en planta y otra para dirección
  • Imagen de marca: tema oscuro industrial premium con dorado corporativo (#D09A40)
  • Arquitectura técnica: elección de tecnologías, flujo de datos y seguridad

2Sistema de gestión para administración (Web)

Aplicación web desde la que la dirección controla toda la fábrica.

2.1 Panel principal (Dashboard)

  • Vista general del estado de la fábrica en tiempo real
  • Indicadores en vivo: máquinas activas, averías, mantenimiento
  • Lista de los últimos trabajos completados
  • Gráfico de distribución de estados

2.2 Gestión de máquinas

  • Alta, modificación y baja de máquinas
  • Estado visible: activa, parada, avería, mantenimiento, inactiva
  • Filtros por estado (solo las averiadas, solo las activas, etc.)
  • Cronómetro en vivo para cada máquina en uso
  • Vista de actividad con histórico completo por máquina

2.3 Gestión de trabajadores

  • Alta, edición y baja de operarios y técnicos
  • Asignación de roles: operario, técnico, supervisor, admin
  • Toggle activo/inactivo (vacaciones, bajas)
  • Control de permisos para operar máquinas

2.4 Sistema de alertas

  • Listado centralizado de máquinas averiadas con motivo
  • Trabajos cerrados con incidencias (resultado KO)
  • Trazabilidad: quién reportó qué y cuándo

2.5 Informes y exportaciones

  • Filtros por rango de fechas y por máquina específica
  • Excel detallado: columnas adaptativas según tipo de máquina + hoja de mantenimientos
  • PDF tabla detallada: informe completo por máquina
  • PDF resumen ejecutivo: KPIs, gráficas y rankings
  • Lógica inteligente: las sinterizadoras incluyen datos de preparación, las fresadoras no

3Aplicación para trabajadores (APK Android)

Aplicación móvil instalada en las tablets de planta. Diseñada para uso táctil y sin formación previa.

3.1 Diseño optimizado para tablets

  • Interfaz táctil con botones grandes (uso con guantes)
  • Sin contraseñas: acceso inmediato
  • Texto grande, legible a distancia
  • Código de colores visible de un vistazo

3.2 Panel de planta

  • Vista general de todas las máquinas con su estado
  • Ordenación inteligente: primero las libres, luego en uso, mantenimiento, averías
  • Oculta automáticamente las máquinas retiradas
  • Muestra quién trabaja en cada máquina y hace cuánto

3.3 Menú de selección al tocar una máquina

Producción
Iniciar un trabajo de producción con el flujo guiado.
Mantenimiento
Registrar una intervención técnica sobre la máquina.
Reportar avería
Marcar la máquina como fuera de servicio.
Cerrar trabajo
Al tocar una máquina en uso, permite cerrar el proceso.

3.4 Flujo de producción (paso a paso)

¿Quién prepara? — Solo para máquinas que requieren preparación (sinterizadoras)
¿Quién lanza el programa? — Solo para CNC Fanuc / Biomill
Confirmar y empezar — Cronómetro en marcha, máquina marcada como "En uso"

3.5 Flujo de mantenimiento

Selección del técnico que realiza la intervención
Tipo: preventivo, correctivo o predictivo
Descripción de la intervención
Confirmar — la máquina queda marcada en mantenimiento

3.6 Flujo de cierre

¿Quién cierra el trabajo?
¿Ha ido todo bien? → Todo OK / Hubo un problema
Si hubo problema: describir qué pasó (queda registrado como incidencia)

3.7 Reporte de averías

  • Accesible en cualquier momento desde el menú de la máquina
  • Selección de quién lo reporta + descripción del problema
  • La máquina queda bloqueada hasta que el admin la resuelva
  • El administrador recibe la alerta al instante en su pantalla

4Base de datos profesional

Estructura robusta, segura y preparada para crecer.
  • 7 tablas relacionadas: perfiles, máquinas, historial de estados, usos de equipo, incidencias, mantenimientos, alertas
  • 28 políticas de seguridad que controlan quién puede ver/modificar qué datos
  • Automatismos: cambios de estado de máquinas se sincronizan automáticamente
  • Funciones especiales para reportar y resolver averías desde las tablets
  • Modo de respaldo local: la aplicación funciona incluso sin conexión para pruebas

5Sincronización en tiempo real

Todos los dispositivos siempre actualizados, sin refrescar.
  • Si un trabajador inicia un uso en una tablet, el admin lo ve al instante
  • Si el admin resuelve una avería, las tablets se actualizan solas
  • Múltiples tablets funcionando a la vez sin conflictos
  • Notificaciones visuales de cambios importantes

6Aplicación móvil nativa (APK)

Aplicación Android empaquetada, lista para instalar en cualquier tablet.
  • Icono profesional con la "F" dorada corporativa sobre fondo negro
  • Splash screen con el logo al arrancar
  • Pantalla que no se apaga mientras se usa la app (importante en planta)
  • Barra de estado oscura integrada con el diseño
  • La APK solo muestra el panel de planta — sin menús innecesarios para los trabajadores
  • Conectada a la misma base de datos que la web administrativa

7Infraestructura y despliegue

Todo listo para producción con actualizaciones automáticas.
  • Aplicación web: desplegada en la nube (Vercel) con dominio propio
  • Base de datos: servidor VPS propio (Hostinger) con respaldos automáticos
  • Actualizaciones continuas: cada mejora se despliega sin interrupciones
  • Sistema de versiones de APK: todas las compilaciones se guardan numeradas
  • Control de código: todo versionado en repositorio privado
